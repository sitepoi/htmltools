Scope & method

Each tool folder under **/app/ was treated as one tool set: the pair <Base>.html + <Base>.js with the matching <Base>.css. Test harnesses, QA scripts, development plans, migration reports and archived build outputs were excluded from the per-tool scan.

  • Excluded: ship-out/ (exported builds), _docs/, scripts/, node_modules/, support files (qa-*, build-harness-*, DEVELOPMENT-PLAN, MARKET-ANALYSIS, sample-export, backups).
  • Archived tools (folder or file name contains OLD / delete / backup) are listed separately and do not count toward the active totals.
  • Static analysis only: rules that need a live CMS host (relay permissions, runtime errors) cannot be fully proven here.
