SprintTaskManager - Development Plan

Every objection from the market analysis, mapped to a concrete task, plus the extra ideas we can imagine - so we can decide what to apply and in which order.
How to read this plan:
  • Value = the colored score box on each card (1-10). 8-10 green = high impact, 6-7 amber = worthwhile, 1-5 gray = nice to have.
  • Effort = Small (hours), Medium (a day or two), Large (multi-day or needs a decision).
  • Requirement = "pure code" means we can build it inside this tool. "CMS" means the parent CMS must cooperate (permissions, email channel, storage).
  • Objection = the pink badge names which objection from MARKET-ANALYSIS.html section 9 this task answers (O1-O10). Cards without it are additional ideas.
  • Use the filters to sort by value, see one category, or only the objection fixes.
Capacity reality check (Firestore 1MB): the 1MB limit applies per document, not per tool instance. Each sprint is its own document and each task is its own document, so there is no aggregate 1MB wall for the whole tool. Details:
ObjectWhat one document carriesPractical limit
Sprintname, dates, goal, managerId, status (~0.5-2 KB)Unlimited count; a year holds 26 two-week sprints or one year-long sprint - both fine
Tasktext fields + label/attachment/link metadata (~200 bytes per attachment entry; files live in CMS storage URLs, not in the document)Thousands of attachment entries per task; 1 MB ≈ 4,000-5,000 attachments
Tasks per sprinttasks are separate documents - no 1MB constraint on the relationshipUnlimited by storage; the board UI stays smooth to roughly 200-300 visible tasks (see G4)
Userspermitted users come from the CMS access list, not from these documentsNo 1MB impact at all
The real ceilings are the Firestore quotas (free tier: 50K reads and 20K writes per day - a 500-task board costs 500 reads per query) and the 500-operation batch cap (already enforced in the sprint delete). Year-long operation: a single sprint can span any dates including a full year, and any number of sprints can chain across a year - there is no hard limit either way.
