Meeting Notes - Help

User help for Meeting Notes. The single source of truth for how this tool works is its SSOT document (SSOT) - this file explains the same behavior for end users, in plain words. Generated from the tool code + SSOT + AI chat by scripts/generate-docs.js. Updated: 2026-09-28.

1. Overview

Meeting Notes is your board meeting workspace: one agenda with subjects, decisions and action items, a projector view with a countdown per subject, and exports that turn the meeting into finished minutes.

It is for meeting chairs, secretaries and board members who want to keep agenda items on time and leave the meeting with documents already written.

2. Before you start

  • You need access to the Meeting Notes object in your UniconHub app. Editors can change the meeting; viewers can only read it.
  • Open the tool from the application store or the object list. Your changes save automatically - there is no Save button.
  • If the AI Assistant shows a notice, your app has not enabled AI for this tool; everything else still works.

3. Step by step

  1. Open the Meeting tab and fill in the meeting: title, date, time, location, chair and attendees.
  2. On the Subjects tab, click "Add subject" for each agenda item. The tool starts each subject with a 15 minute plan; change it on the edit card if needed.
  3. During the meeting, click "Meeting Mode" to project one subject at a time. Press Start on the timer; the time shows when it runs out. The subject keeps earning spent time the whole time it is on screen.
  4. Record notes in the big editor, add decisions with "Moved by" and "Seconded by", and tick a subject Done when it closes.
  5. Take a break with the "Waiting / break" entry at the bottom of the sidebar - subject time pauses while the break clock runs.
  6. On the Tasks tab, add follow-up actions with an assignee, due date and priority. Assignees come from the people permitted on this object.
  7. Use the AI Assistant to build the summary, extract action items from the raw notes, or draft the minutes.
  8. On the Exports tab, generate the minutes or board PDF, task lists (CSV, XLS, JSON), Markdown or the email summary.

4. Common questions

QuestionAnswer
Why does the timer keep running when I have not pressed Start?The spent time counts from the moment the subject is shown - that is the real meeting time. Start only starts the countdown.
What happens when the countdown reaches zero?It keeps counting in red as overrun, so you can see exactly how long the topic has overshot.
Where do the assignee names come from?From the permission list of this CMS object. If the list is unavailable, you can type any name instead.
Can I reuse last month's meeting?Yes - on the Meeting tab, use Import from another meeting and paste the exported JSON, then merge or replace.
Do I need to save?No. Every change autosaves, including when you close the page.

5. Troubleshooting

ProblemWhat to do
PDF export downloads an HTML file instead of a PDFYour app has PDF export disabled; open the downloaded file and print it to PDF from your browser.
The AI Assistant is empty or shows a noticeThe allowAi parameter is off for this tool. Ask an admin to enable it, or use the auto summary fallback.
Assignee dropdowns are plain text fieldsThe CMS did not return the object permission list. Typing a name still works.
The timer jumps after the tab was in the backgroundExpected - the timer uses the real wall clock, so time spent with the tab hidden still counts.
A subject or task was deleted by mistakeRe-import it from a previous export, or ask the CMS admin for the object's version history.
