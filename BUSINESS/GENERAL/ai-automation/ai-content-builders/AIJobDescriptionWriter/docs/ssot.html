What this tool is

AI Job Description Writer is a single-screen browser tool that turns role details and company context into structured, editable job descriptions and job adverts. Hiring managers and recruiters type a role brief, generate AI drafts, refine each section, run bias and readability checks, and export polished copy. All work is saved locally in the browser with JSON backup, so the tool is private and requires no account. The output covers the full loop from data entry through review to export for job boards and internal use.

Jobs the user hires it for

  • Draft a complete, structured job description from a role brief without starting from a blank page.
  • Create platform-specific job advert variants such as standard job board, short, and social from the same brief.
  • Edit and reorder JD sections while keeping formatting and tone consistent.
  • Check a draft for biased or hard-to-read language and fix flagged issues.
  • Save, reload, and version drafts locally without losing work.
  • Export or copy final copy in Text, Markdown, or HTML for ATS, website, or job board.

Rules the tool follows

  • Required fields before generating: roleTitle, department, location, employmentType, seniority. Missing fields are highlighted and generation is blocked until filled.
  • Salary range is optional. If omitted, export omits the salary line and preview shows 'Salary: Competitive' only when the user enables the placeholder toggle.
  • AI generation must return strict JSON matching the jdSection schema. If parsing fails, show an error and keep the previous draft unchanged.
  • Responsibilities must generate 5 to 8 bullets, each starting with an action verb. Qualifications must be split into Must-have and Nice-to-have sections.
  • Readability target is Flesch-Kincaid grade 8 to 10. Flag sentences longer than 25 words and bias terms from a built-in list such as 'rockstar', 'ninja', 'young', 'digital native'.
  • Output variants enforce character limits: standard job board 800, short 300, social 150. Over-limit content is truncated with a visible warning.
  • Autosave occurs 800ms after the last edit. The tool keeps the last 10 versions per role brief. JSON export includes roleBrief, jdSections, outputVariants, and qualityReport.
  • The tool never calls external URLs directly. All AI requests use the parent-provided `tool.requestFetch` relay only.

Explicitly out of scope

  • No account system, multi-user collaboration, or cross-device sync in version 1.
  • No direct posting to job boards, ATS/HRIS integration, or candidate management.
  • No legal or HR compliance certification. The tool flags likely issues, but final review is the user's responsibility.
  • No resume parsing, candidate sourcing, screening, or applicant tracking.
  • No multi-language UI or AI-generated output beyond English in version 1.

How success is checked

  • A reviewer can complete a role brief, generate a JD, edit a bullet, and export Markdown copy in under 2 minutes.
  • Generated JD contains at least 5 responsibilities and separated Must-have and Nice-to-have qualifications.
  • Readability score and bias flags update immediately after an edit.
  • Reloading the page restores the last saved draft from localStorage.
  • Exported text has no unresolved placeholders such as [Role] or Lorem ipsum.
  • The visible UI badge shows the current build identifier and the console first line logs the same identifier.
