Profiles

Copy a profile preset into the CMS parameter profileConfig. The preset library is reference metadata; the usage register in SSOT section 4.1 is the authoritative statement of which preset an application uses.

How to use a preset
  1. Choose a card below and copy its JSON.
  2. Open the tool settings in the CMS and find App profile config (JSON).
  3. Paste the JSON and save. Do not paste it into profileDefinitions.
  4. Update SSOT section 4.1 with the usage status and the segments enabled.

The status control on each card is a browser-local reminder only. It does not change a CMS configuration and it is not shared with the team.
