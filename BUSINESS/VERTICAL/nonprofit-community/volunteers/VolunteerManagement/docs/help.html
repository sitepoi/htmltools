Volunteer Management - Help

User help for Volunteer Management. The single source of truth for how this tool works is its SSOT document (SSOT) - this file explains the same behavior for end users, in plain words. Generated from the tool code + SSOT + AI chat by scripts/generate-docs.js. Updated: 2026-09-21.

1. Overview

Volunteer Management is the event page's volunteer hub: managers approve applications, assign tasks, track hours and issue certificates, while volunteers register, see their tasks and log their hours.

It is for event managers of charities and nonprofits, and for the volunteers they coordinate. One tool instance manages one event; a shared volunteer registry remembers volunteers across events.

2. Before you start

  • Event managers need the editor or admin role on the event object; volunteers only need access to the event page.
  • The field settings must enable object CRUD with the volunteer registry type (volunteerRegistry-uniconbaseapps) and the four event types. If the registry type is missing, the tool shows a configuration banner.
  • Open the event object in the CMS and find the Volunteer Management field.

3. Step by step

  1. Register as a volunteer. Open the event page, click Register as Volunteer, fill in your skills and availability, and submit. Managers see your application under Pending Approvals.
  2. Approve volunteers (managers). Open the Volunteers tab or the Pending Approvals card and click Approve or Reject. Use Add Volunteer to add a permitted user directly.
  3. Create and assign tasks (managers). Open the Tasks tab, click Create Task, and fill in the name, description, assignee, due date and estimated hours.
  4. Work on tasks (volunteers). Open the Tasks tab, click Start, do the work, then click Mark Complete.
  5. Log hours (volunteers). Click Log Hours, pick the task, date and hours, and describe what you did. Managers approve the hours in the Hours tab.
  6. Get the certificate. Open the Certificate tab to preview your certificate, then download it as PDF or send it by email.

4. Common questions

QuestionAnswer
I applied for an event before - why do I apply again?Your profile stays in the shared registry, but each event needs its own application. Skills and contact data are not re-entered.
When does my certificate show hours?Only hours with status Approved count toward the certificate total.
Can managers message one volunteer only?Yes - in the Messages tab, managers can pick one volunteer or message all approved volunteers.
Can I re-apply after a rejection?Yes - your status card shows a Re-apply button, and the application goes back to pending.

5. Troubleshooting

ProblemWhat to do
The Volunteers tab shows a red registry warningThe volunteer registry type is not authorized. An admin must add volunteerRegistry-uniconbaseapps to settings.allowedObjectTypes and enable object CRUD.
The Approve button is missing for a volunteerThe application was already processed, or the volunteer's registry profile is banned. Refresh the page and check the Volunteers tab.
Hours do not appear in my certificateOnly approved hours count. Ask the manager to approve pending logs in the Hours tab.
A long message was refusedMessages are limited to 8,000 characters - split longer text into several messages.
