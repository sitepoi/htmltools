Buyer questions

Where does the curriculum come from?

From the Curriculum Builder tool - you pick the course in Setup and this tool reads it. Curriculum authoring stays where it belongs.

Is the target end date a hard deadline?

No. It is a recommended pace guide. The app shows ahead / on schedule / behind to help the student, and study always stays open.

What does the shared link open?

The exact course page the supervisor was on. The CMS provides the page URL automatically, and an optional Course Page Link in Setup can override it.
