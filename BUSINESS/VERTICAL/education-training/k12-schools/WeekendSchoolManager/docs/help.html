Weekend School Manager - Help

User help for Weekend School Manager. The single source of truth for how this tool works is its SSOT document (SSOT) - this file explains the same behavior for end users, in plain words. Generated from the tool code + SSOT + AI chat by scripts/generate-docs.js. Updated: 2026-09-30.

1. Overview

Weekend School Manager keeps every record of your weekend school in one place: students, Sunday attendance, monthly payments, Quran progress, parent communication and weekly and monthly reports.

It is built for the coordinators, teachers and administrators of weekend and Quran schools who run the school on paper, notebooks and group chats today. Everything autosaves, so nothing is lost when the phone or browser closes.

2. Before you start

  • Open the tool from your school page in the CMS. Your account needs an editor or administrator role to make changes; viewers can only read.
  • On first use, open Settings and fill in the school name, currency, class groups, lessons and payment brackets.
  • Click "Load Sample Data" in the test harness only when trying the tool without real data - never with real student names.

3. Step by step

  1. Open Settings and set the school name, currency, class groups, lessons and payment brackets. They are used everywhere else.
  2. Go to Students and click + Add Student. Fill the first name at least, then the class group, parents, contacts and health notes. Save.
  3. On Sunday, open Attendance and click each student's cell per lesson to cycle the mark (P present, A absent, L late, E excused). Click "Mark Week Complete" when done.
  4. Open Payments each month and set each student's status; the waiting list below shows every unpaid amount with its due date. Use "Build Late Reminder" to copy a polite message per family.
  5. Open Progress or a student's drawer to add notes, teacher contacts, Quran reading level and memorized surahs.
  6. Open Reports before the parent meeting, choose Monthly, then Copy Text or Download .txt or Print / PDF.

4. Common questions

QuestionAnswer
What does the P / A / L / E cell mean?Present, Absent, Late, Excused. Click the cell again to move to the next mark.
How do I remind a parent about a payment?Open Payments and click "Build Late Reminder" - it prepares one polite message per family in English or Turkish. Copy and send it from your phone.
Can I send a message as a WhatsApp image?Yes - in a payment or Quran message click "Copy as Image", then paste it into WhatsApp.
What happens if the data gets big?The sidebar shows a size meter, and Settings has a data panel with warnings. Use "Export All Data (JSON)" to keep a backup.
Can teachers edit but not delete?Yes - editors can enter records; deleting students, group messages and suggestions is administrator-only.

5. Troubleshooting

ProblemWhat to do
Changes do not save automaticallyCheck the warning message about the CMS field setting allowRequestSave and save the form manually until it is set to yes.
Upload shows "not available"The CMS field setting allowUpload must be yes for the tool field.
Send Email shows "not available"The CMS field setting allowSendEmail must be yes, and the parent needs an email address in Edit Info.
Print / PDF does nothingUse "Download .txt" instead - the text contains the same report.
A student is missing from the listCheck the group filter chip and the search box on the Students page - the student may be filtered out.
