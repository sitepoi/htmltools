1. Purpose and governance

Single source of truth for the school console. Same governance rules as the tool family: decisions in section 11, append-only register, this document wins ties.

Core guarantee. The console never edits objects - it only lists and opens them; the folder map is resolved from the settings object BEFORE any folder-based query runs, so every tab shows the correct year.

6. Requirements

  1. Never edit objects; only list and open.
  2. Folder map resolved BEFORE any folder-based query (D-SCO-01 - a race made every tab empty on the first build).
  3. Teacher users see only what the CMS ACL returns - no client-side permission guessing.
  4. Own value stays light: only UI state.

8. Solution design

8.1 Default data format (own value - UI state only)

{ "version": 1, "ui": { "tab": "students" } }

8.2 Load pipeline (staged)

loadAll() - query settings (recordKind schoolSettings) - resolve folderMap
          - requestFolders - find attendance subfolders (parentId match)
          - query students / lessons / attendance subfolders / payments
          - render active tab

8.3 Params

ParamPurpose
appObjectTypeApplication id, default weekendSchool
folderMapJsonFallback when no settings object is readable
attendanceFolderIdsFallback comma-separated subfolder ids when requestFolders is unavailable

17. Test plan - step by step

All tests run in the local test harness (app/test-harness.html) served with python -m http.server 8765 and driven by headless Edge. The harness supports ?sample=1 (fresh sample data), ?tab=<pane> and ?actions=<list> (runs clicks after 500 ms; sub-actions set-input:<id>:<value>, clear-folder:<key>, check:<id>, set-select:<id>:<value>).

17.1 Scenarios

  1. H-01 - renders with sample data. Steps: open the harness with ?sample=1 and each ?tab=. PASS if: every pane renders data without console errors.
  2. H-02 - every button reacts. Steps: run the recorded ?actions= sequences for each button. PASS if: the expected dialog opens / row appears / cell toggles.
  3. H-03 - persistence. Steps: edit a field, wait 500 ms, press "Show log". PASS if: requestSave was accepted and the value survives a reload.
  4. H-04 - role cycle. Steps: switch role to editor / viewer / none. PASS if: write controls disable for read-only roles and nothing throws.
