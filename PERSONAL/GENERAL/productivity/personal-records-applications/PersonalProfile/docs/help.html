Personal Profile - Help

User help for Personal Profile. The single source of truth for how this tool works is its SSOT document (SSOT) - this file explains the same behavior for end users, in plain words. Generated from the tool code + SSOT + AI chat by scripts/generate-docs.js. Updated: 2026-11-05.

1. Overview

Personal Profile keeps one record of you and reshapes it for whatever you are applying to: a resume, a university program, a scholarship, a volunteer role, an immigration form or a care form.

It is for anyone who fills the same personal details into different forms. Type a fact once here, then copy or download it when a form asks. Private details are only asked when the profile you choose actually needs them, and share and export live in the menu behind your avatar, not in the section list.

2. Before you start

  • The record saves itself. There is no Save button; the indicator at the top right shows when the last change was written.
  • If your CMS account is signed in, the tool fills your name and email into an empty record once. You can change either value.
  • Private details (date of birth, nationality, marital status, gender and pronouns) appear only for immigration, government and health profiles. Leave anything empty that your forms never ask for.
  • Documents are stored as links, so keep the actual files in a place you control.

3. Step by step

  1. Add your identity first. Basic Information starts with your photo, your name, and the email and phone that go at the top of every application. Add a photo if you have one; it also appears in the header.
  2. Pick the profile use. Continue to the second block and choose the application this profile is mainly for. The sidebar immediately shows the sections that use needs.
  3. Adjust the areas. Tick or untick the cards under "What this profile covers". Unticking an area hides the sections only that area needed, and leaves any section that another selected area still uses. "Use suggested areas" restores the set suggested by the profile use.
  4. Fill the core sections. Complete Basic Information and then Profile Summary. The summary is shown as read-only cards: open Edit on one card, save it, and the other cards stay readable. Each editor shows an example sentence - press "Use this example" if you want a starting point.
  5. Add repeatable records. In Education, Work Experience, Skills, References and the other list sections, each entry is a card with its key facts. Use Edit to open the fields and Done to close them; a new entry opens by itself so you can type straight away.
  6. Add unusual fields. Use the plus button in a section header to add an extra field, or "+ New custom section" in the sidebar for a whole section of your own.
  7. Check what is missing. Open your avatar in the top right and choose Share & export. The readiness list shows the most important missing items first.
  8. Take it with you. Copy summary gives you plain text for a form. Copy JSON or Download JSON gives you the full record. Personal details and sensitive sections are left out until you tick "Include sensitive sections".

4. Common questions

QuestionAnswer
Does changing the profile use delete anything?No. It only changes which sections the sidebar shows. Every saved answer stays in the record, and Show all sections brings every section back.
Can one record serve a university application and a job application?Yes. Switch the profile use, fill what the new use needs, then switch back. The same education, work and reference entries are reused.
What does the ring in the header count?Visible sections whose required checks are all filled. Sections with no required checks (for example Personal Details) are marked Optional and do not count.
Where do my files go?Only the link and file name are stored. The file itself stays wherever the link points.
Who can see sensitive sections?Anyone who can open this CMS record. The tool keeps personal details, identity, health and funding out of exports by default, but it cannot change who may read the record.
Why do I only see a few sections at first?A record with no profile use shows only the basic sections: Basic Information, Profile Summary, Contact, Education and Skills. Choose a profile use or tick an area and the related sections appear. Show all sections reveals everything at any time.
Where is my date of birth or nationality?Those fields live in Personal Details, which appears only for immigration, government and health profiles. The tool asks for the year of birth; the full date is optional and only needed when an official form demands it.
Where did Share & Export go?Open the avatar in the top right. The menu holds Share & export, Copy summary, Copy JSON and Download JSON. Share opens a panel with the readiness list, the export options and the preview - it is an action on the record, not a section you fill in.
Will an example overwrite what I typed?No. The example is only shown as help. Pressing "Use this example" replaces the text in that editor, and nothing is saved until you press Save.
Why do the summary cards and list entries look read-only?They are meant to be read first. Press Edit on one card or one list entry; the fields open for that item only, and Done or Save closes them. This keeps a long profile scannable.
Why do documents show a warning?A document or certification expires within 90 days, or has already expired. Update the record and the link before you submit an application.
What happens when the record is read-only?You can still read every section, see readiness and copy the summary. Editing, adding and removing are hidden.

5. Troubleshooting

ProblemWhat to do
Copy did nothingThe browser blocked clipboard access inside the frame. Select the text in the Summary preview and copy it manually.
Upload is not availableThis field does not allow uploads. Paste a public link into the file field instead.
A section I need is missingChoose a profile use or tick the matching area in "What this profile covers"; before that, only the basic sections show. Show all sections in the sidebar reveals everything.
My last keystrokes were lostWait for the save indicator to return to "All changes saved" before closing the record.
The summary has an old valueThe summary is rebuilt from the record. Reopen Share & export from the avatar menu after saving.
