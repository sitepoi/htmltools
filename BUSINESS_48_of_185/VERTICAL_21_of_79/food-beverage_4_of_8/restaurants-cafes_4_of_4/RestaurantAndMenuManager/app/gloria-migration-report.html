5. Critical Gaps Summary

🔴 What We're Missing

1. Per-option Out of Stock
Gloria has option.is_out_of_stock — individual modifier options can be marked unavailable. Our OOS is only at the item level. Impact: Medium. Workaround: split the option into a separate group or remove it temporarily.
2. Min/Max Selection Count (force_min / force_max)
Gloria allows "pick exactly 1", "pick 1–3", "pick up to 5". We only have "pick one" vs "pick any". Impact: High for combo/family deals. This is the biggest functional gap.
3. Tax Category Integration (tax_category_id)
Gloria links items and modifier groups to tax categories. Our menu model has no tax reference. Impact: Low if tax is handled at POS/ordering level rather than menu level.

🟡 Partial / Needs Conversion

4. Deduplication of Modifier Groups
Gloria repeats the same group definition across items and sizes. Import must detect identical groups (by name + options) and merge them into a single global group, then assign the unified ID.
5. Ingredients / Allergens
Gloria uses free-text ingredients and additives fields. We have a structured allergens[] picker. Import would need NLP or manual mapping.
6. Category Pictures
Gloria supports picture_id on categories. We don't. Low priority — most menu systems don't use category images.

6. Strengths of UniconHub vs Gloria

✅ Per-Assignment Modifier Overrides
Gloria has no override concept — if a modifier group is required, it's required everywhere. UniconHub allows per-product and per-size overrides for is_required and allow_duplicates.
✅ Unified Visibility System
Gloria has 4+ separate fields controlling visibility (active, active_begin, active_end, active_days, active_exact_from, hidden_until). UniconHub consolidates into a clean 3-mode system: Show / Scheduled / Hide with clear sub-options.
✅ Channel Filtering
UniconHub has show_on_channels[] — explicitly controls which service channels (pickup/delivery/on-premise) an item appears on. Gloria's restaurant_menu_availabilities[] is more complex but serves a similar purpose.
✅ Global Modifier Groups
Editing a modifier group once updates all items using it. Gloria's inline duplication means editing "Toppings" on 20 pizzas requires 20 separate edits.
✅ Modifier Usage Tracking
UniconHub shows where each modifier group is used across the menu. Gloria has no such visibility.

7. Import Conversion Map

Step-by-Step Conversion Logic

// Pseudo-code for Gloria → UniconHub import

function importGloriaMenu(gloriaJson) {
  const result = { menu: { categories: [], items: [], modifier_groups: [] } };

  // 1. COLLECT & DEDUPLICATE all modifier groups
  const groupMap = new Map(); // key → unified group
  function unifyGroup(gloriaGroup) {
    const key = gloriaGroup.name + '|' + gloriaGroup.options.map(o => o.name).sort().join(',');
    if (!groupMap.has(key)) {
      groupMap.set(key, {
        id: uid(),
        group_name: gloriaGroup.name,
        selection_type: (gloriaGroup.force_max === 1 && gloriaGroup.force_min === 1) ? 'single' : 'multi',
        allow_duplicates: gloriaGroup.allow_quantity || false,
        is_required: gloriaGroup.required || false,
        options: gloriaGroup.options.map(o => ({
          id: uid(), option_name: o.name,
          price_adjustment: o.price || 0,
          is_default: o.default || false,
          is_available: !o.is_out_of_stock
        }))
      });
    }
    return groupMap.get(key);
  }

  // 2. CONVERT categories
  for (const gCat of gloriaJson.categories || []) {
    const cat = {
      id: uid(),
      name: gCat.name,
      description: gCat.description || '',
      visibility_mode: resolveVisibility(gCat),
      hide_until_date: gCat.hidden_until || null,
      schedule_type: gCat.active_exact_from ? 'date_range' : (gCat.active_days ? 'time_windows' : null),
      schedule_from: gCat.active_exact_from || gCat.active_begin || null,
      schedule_until: gCat.active_exact_until || gCat.active_end || null,
      schedule_time_windows: gCat.active_days ? bitmaskToDays(gCat.active_days) : null
    };
    result.menu.categories.push(cat);

    // 3. CONVERT items
    for (const gItem of gCat.items || []) {
      const item = {
        id: uid(),
        category_id: cat.id,
        item_name: gItem.name,
        description: gItem.description || '',
        price: gItem.sizes?.length ? null : (gItem.price || 0),
        tags: gItem.tags ? gItem.tags.split(',').map(t => t.trim()) : [],
        visibility_mode: resolveVisibility(gItem),
        hide_until_date: gItem.hidden_until || null,
        schedule_type: gItem.active_exact_from ? 'date_range' : (gItem.active_days ? 'time_windows' : null),
        schedule_from: gItem.active_exact_from || gItem.active_begin || null,
        schedule_until: gItem.active_exact_until || gItem.active_end || null,
        schedule_time_windows: gItem.active_days ? bitmaskToDays(gItem.active_days) : null,
        availability: 'available',
        show_on_channels: gItem.restaurant_menu_availabilities?.map(a => a.service) || [],
        sizes: [],
        modifier_group_ids: [],
        modifier_group_overrides: {}
      };

      // Convert item-level modifier groups
      for (const gGroup of gItem.groups || []) {
        const unified = unifyGroup(gGroup);
        item.modifier_group_ids.push(unified.id);
        if (gGroup.required !== undefined || gGroup.allow_quantity !== undefined) {
          item.modifier_group_overrides[unified.id] = {};
          if (gGroup.required !== undefined) item.modifier_group_overrides[unified.id].is_required = gGroup.required;
          if (gGroup.allow_quantity !== undefined) item.modifier_group_overrides[unified.id].allow_duplicates = gGroup.allow_quantity;
        }
      }

      // Convert sizes
      for (const gSize of gItem.sizes || []) {
        const size = {
          id: uid(), label: gSize.name,
          price: gSize.price || 0, modifier_group_ids: []
        };
        for (const gGroup of gSize.groups || []) {
          const unified = unifyGroup(gGroup);
          size.modifier_group_ids.push(unified.id);
        }
        item.sizes.push(size);
      }
      result.menu.items.push(item);
    }
  }

  // 4. Add unified modifier groups
  result.menu.modifier_groups = Array.from(groupMap.values());
  return result;
}

8. Bitmask → Days Conversion

Gloria uses a bitmask where Monday=1, Tuesday=2, Wednesday=4, Thursday=8, Friday=16, Saturday=32, Sunday=64. The sum represents active days (e.g., 31 = Mon-Fri).

function bitmaskToDays(mask) {
  const days = [];
  for (let i = 0; i < 7; i++) {
    if (mask & (1 << i)) days.push(i + 1); // 1=Mon … 7=Sun
  }
  return [{ days, start_time: '00:00', end_time: '23:59' }];
}

9. Recommendation

For Customer Migration

  1. Build the importer using the logic above. Estimated effort: 1–2 days.
  2. Add force_min/force_max to modifier groups. This is the #1 functional gap and directly impacts combo/family deals which are common in pizza restaurants (the sample Gloria data is a pizzeria).
  3. Add per-option OOS (is_out_of_stock on options). This is common in restaurant operations — individual ingredients run out.
  4. Tax category can be deferred — most ordering platforms handle tax at checkout, not at the menu level.
  5. Run a test migration with the actual customer's Gloria export, review differences manually, then iterate.
