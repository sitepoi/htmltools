1. How to use this list

Main target, one sentence: produce finished, verified work with AI - content packs first, application testing second, small applications third - and prove every result with evidence.

Working split: about 40 percent content, 35 percent testing, 25 percent building.

Work from top to bottom. Do not start a task until the one above it is accepted or marked no-action. Every task has one expected output and one piece of evidence. If you cannot show the evidence, the task is not done.

  • One artifact at a time. Never run two builds or two content packs in the same day.
  • Two streams maximum per week. The list already enforces this.
  • 30-minute rule. Blocked for 30 minutes means report it and move to the next task on the list.
  • Everything is written. Decisions, defects and answers live in the log, not in chat.
  • Tick the box only when your manager accepted the task or you recorded its evidence.

Never: git commands, database access, publishing, editing existing tools or shared rules, testing on live data, inventing a fact or a number. Report instead.

6. Definition of done

Test report

  • ID, artifact, test action, numbered steps, expected and actual result.
  • One screenshot or copied message as proof.
  • Severity set, duplicates merged, reproducible in under a minute.

Small application

  • Template files, local test page, all automated checks pass.
  • Acceptance lines and 12 attacks run, results recorded.
  • Screenshots, five-bullet explanation, short handover note.

Content pack

  • Brief, source list with dates, structure with page references.
  • Every item complete, each factual statement traceable to a source page.
  • Coverage list at 100 percent, or written exclusions with reasons.
  • Learner walk-through recorded, confusion points fixed, review pack written.

7. If something is blocked

1. Retry onceRun the same step again exactly as written. Copy the error message word for word.
2. Report in writingTask ID, what you did, what happened, the message, what you already tried.
3. Move onTake the next task on the list. Do not invent a workaround, install anything, or touch another folder.

A blocked task that is reported in 30 minutes costs one hour. A blocked task that is hidden costs a week. Reporting is the job.

Counts are targets, not quotas to fake. If a week produces fewer accepted artifacts, the gate is not met, whatever the tick boxes say. Companion documents: the one-page job description, the detailed job description, and the decision summary, all in this folder.
