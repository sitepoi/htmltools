How to use this harness. Pick a page above and it renders exactly the way the CMS composes it: the central header, then the page fragment, then the central footer.
Served mode: open this file through a local server (for example npx serve . or VS Code Live Server) and the harness reads header-footer/header.html, the page file and header-footer/footer.html straight from disk. Edit a file, hit Reload, done.
File mode: if you just double-click this file, browsers block local file reads, so the harness shows the snapshot embedded when the harness was built. Edit a page, then run node build-test-harness.js again and refresh.
Links behave like the CMS: the pages link with routes (/, /how-it-works, /about-us), never with .html. Clicking any internal link stays inside this harness and renders that page here; a route that has no page yet shows a blue notice instead of navigating away.
Deep links: test-harness.html?page=how-it-works or test-harness.html#how-it-works.
Remember: add new pages to the PAGES list in build-test-harness.js and rebuild, so every page stays testable here.
