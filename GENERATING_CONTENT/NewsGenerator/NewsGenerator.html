    🚀 Publish the story

    Two routes into the platform — pick whichever fits your CMS workflow.

    1 · Page object JSON

    One JSON that contains everything: name, slug, data.htmlPage.code.{html,css,js} and seo. Create the page object in your site app with this payload.

    2 · Generator output

    The plain === HTML / CSS / JS / SEO / PAGE META === sections used by the page generator — paste into the CMS tool builder fields.

    3 · Proof & share

    Open a standalone HTML copy for quick proofing, or send it to the CMS print pipeline as a PDF.
