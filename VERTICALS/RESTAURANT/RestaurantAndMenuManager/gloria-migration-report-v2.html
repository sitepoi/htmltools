1. What Changed — v1 → v2

All 8 Previously-Identified Gaps Are Now Resolved

✅ GAP 1: force_min / force_max — NOW COVERED
Modifier groups now support force_min (min selections) and force_max (max selections, 0=unlimited). Direct 1:1 mapping to Gloria's force_min/force_max.
✅ GAP 2: Per-Option Out of Stock — NOW COVERED
Each modifier option now has availability ("available"|"out_of_stock"), oos_type ("tomorrow"|"date"|"undetermined"), and oos_until. Maps directly to Gloria's is_out_of_stock — and goes further with time-bound OOS.
✅ GAP 3: tax_category_id — NOW COVERED
Tax category reference added to all three levels: category.tax_category_id, item.tax_category_id, and modifier_group.tax_category_id. Matches Gloria's tax category model.
✅ GAP 4: Category Pictures — NOW COVERED
Categories now have photos[] + primary_photo_url — a full gallery with drag-to-reorder and primary selection. Exceeds Gloria's single picture_id.
✅ GAP 5: Ingredients / Additives — NOW COVERED
Items now have free-text ingredients and additives fields. Direct mapping to Gloria's fields of the same name.
✅ GAP 6: Deduplication of Modifier Groups — IMPORT LOGIC EXISTS
The import pseudo-code already handles deduplication by name + options signature. No data model change needed.
✅ GAP 7: Modifier Group Photos — NOW COVERED
Modifier groups now support photo_url (single photo). Gloria doesn't have this — it's a net-new feature.
✅ GAP 8: Modifier Option Photos — NOW COVERED
Modifier options now support photo_url (single photo). Gloria doesn't have this — it's a net-new feature.
✅ GAP 9: hide_instructions — NOW COVERED (v2.1)
Items now have a hide_instructions boolean toggle. When ON, the special instructions input field is hidden from customers during ordering. Direct 1:1 mapping to Gloria's field.
✅ GAP 10: Kitchen internal names — NOW COVERED (v2.1)
Both items and modifier options now support show_internal_name + internal_name. When enabled, the kitchen display ticket shows the internal name instead of the customer-facing name. This exceeds Gloria's capabilities.

6. Remaining Gap (Minor Only)

🟡 What's Still Not 1:1

1. Gloria extras Objects (sku, country_value, country_condition)
Gloria attaches miscellaneous metadata to items, sizes, options, and groups. These are Gloria-internal fields with no menu-structural purpose. Impact: None. Not relevant to the menu data model.

✅ Resolved in Import Layer (not a feature gap)

Numeric vs String Tax Category IDs
Gloria uses numeric tax_category_id (e.g. 444286). UniconHub uses the tax category name as a string reference. A simple lookup table during import maps numeric Gloria IDs to UniconHub tax category names. No data model change needed.

🚫 Intentionally Skipped

Per-option Channel Filtering (restaurant_menu_availabilities on options)
Gloria supports per-option channel availability. UniconHub filters channels at the item level. Per-option channel filtering was evaluated and determined to be unnecessary — it is rarely configured on individual options in real-world menus.

7. New UniconHub Features Beyond Gloria

🟣 What UniconHub Has That Gloria Doesn't

✅ Dietary Marks (dietary_marks[])
Chip-based dietary labels: Hot, Vegan, Vegetarian, Gluten Free, Halal, Dairy Free, Raw, Nut Free. Customers can filter by dietary preference.
✅ Nutritional Values Table (nutrition[])
Full nutrition facts with 9 nutrients (Calories, Carbs, Fat, Protein, Sugar, Salt, Sat Fat, Fiber, Sodium). Supports per-serving or per-100g modes. When items have sizes, each size gets its own column.
✅ Per-Assignment Modifier Overrides
Modifier group settings (is_required, allow_duplicates) can be overridden per item. Gloria's groups are always the same everywhere they appear.
✅ Category Photo Galleries
Multiple photos per category with drag-to-reorder and primary selection. Gloria only supports a single picture_id.
✅ Modifier Group & Option Photos
Visual ingredient references for both modifier groups and their individual options. Helps customers see what they're selecting.
✅ Unified Visibility System
Clean 3-mode system (Show / Scheduled / Hide) replaces Gloria's 6+ separate visibility fields. Easier to understand and maintain.
✅ Global Modifier Groups
Edit a modifier group once, all items using it update automatically. Gloria duplicates group definitions across items.
✅ Kitchen Internal Names (show_internal_name + internal_name)
Both items and modifier options can have an internal/kitchen name that displays on kitchen tickets instead of the customer-facing name. Keeps the kitchen organized with short codes (e.g. "CHIX-WRAP") while customers see the full description.
✅ Hide Special Instructions (hide_instructions)
Per-item toggle to suppress the customer special-instructions input field. Useful for standardized items where custom requests don't apply (e.g. sealed beverages, pre-packaged goods).

8. Updated Import Conversion Map (v2)

Step-by-Step Conversion Logic — Updated for v2 Fields

// Pseudo-code for Gloria → UniconHub v2 import

function importGloriaMenu(gloriaJson, taxLookupMap) {
  const result = { menu: { categories: [], items: [], modifier_groups: [] } };

  // 1. COLLECT & DEDUPLICATE all modifier groups
  const groupMap = new Map();
  function unifyGroup(gloriaGroup) {
    const key = gloriaGroup.name + '|' +
      (gloriaGroup.options || []).map(o => o.name).sort().join(',');
    if (!groupMap.has(key)) {
      groupMap.set(key, {
        id: uid(),
        group_name: gloriaGroup.name,
        selection_type: (gloriaGroup.force_max === 1 && gloriaGroup.force_min === 1)
          ? 'single' : 'multi',
        allow_duplicates: gloriaGroup.allow_quantity || false,
        is_required: gloriaGroup.required || false,
        force_min: gloriaGroup.force_min || 0,           // v2
        force_max: gloriaGroup.force_max || 0,           // v2
        tax_category_id: taxLookupMap[gloriaGroup.tax_category_id] || null, // v2
        photo_url: null,                                  // v2 (no Gloria source)
        options: (gloriaGroup.options || []).map(o => ({
          id: uid(),
          option_name: o.name,
          price_adjustment: o.price || 0,
          is_default: o.default || false,
          is_available: true,
          availability: o.is_out_of_stock ? 'out_of_stock' : 'available', // v2
          oos_type: o.is_out_of_stock ? 'undetermined' : null,            // v2
          oos_until: null,                                                 // v2
          photo_url: null                                                  // v2
        }))
      });
    }
    return groupMap.get(key);
  }

  // 2. CONVERT categories
  for (const gCat of gloriaJson.categories || []) {
    const cat = {
      id: uid(),
      name: gCat.name,
      description: gCat.description || '',
      visibility_mode: resolveVisibility(gCat),
      hide_until_date: gCat.hidden_until || null,
      schedule_type: gCat.active_exact_from ? 'date_range'
        : (gCat.active_days ? 'time_windows' : null),
      schedule_from: gCat.active_exact_from || gCat.active_begin || null,
      schedule_until: gCat.active_exact_until || gCat.active_end || null,
      schedule_time_windows: gCat.active_days
        ? bitmaskToDays(gCat.active_days) : null,
      photos: [],                                        // v2 (no Gloria source)
      primary_photo_url: null,                           // v2
      tax_category_id: null                              // v2 (no Gloria source on categories)
    };
    result.menu.categories.push(cat);

    // 3. CONVERT items
    for (const gItem of gCat.items || []) {
      const item = {
        id: uid(),
        category_id: cat.id,
        item_name: gItem.name,
        slug: slugify(gItem.name),
        description: gItem.description || '',
        price: gItem.sizes?.length ? null : (gItem.price || 0),
        sale_price: null,
        primary_photo_url: null,
        photos: [],
        allergens: [],                                   // needs manual mapping
        dietary_marks: [],                               // v2 (no Gloria source)
        is_vegetarian: false, is_vegan: false, is_gluten_free: false,
        spice_level: 0,
        calories: null,
        prep_time_minutes: null,
        ingredients: gItem.ingredients || '',            // v2 — direct mapping
        additives: gItem.additives || '',                // v2 — direct mapping
        nutrition_per: 'serving',                        // v2 (no Gloria source)
        nutrition: [],                                   // v2 (no Gloria source)
        tags: gItem.tags ? gItem.tags.split(',').map(t => t.trim()) : [],
        modifier_group_ids: [],
        modifier_group_overrides: {},
        sizes: [],
        visibility_mode: resolveVisibility(gItem),
        hide_until_date: gItem.hidden_until || null,
        schedule_type: gItem.active_exact_from ? 'date_range'
          : (gItem.active_days ? 'time_windows' : null),
        schedule_from: gItem.active_exact_from || gItem.active_begin || null,
        schedule_until: gItem.active_exact_until || gItem.active_end || null,
        schedule_time_windows: gItem.active_days
          ? bitmaskToDays(gItem.active_days) : null,
        availability: 'available',
        show_on_channels: (gItem.restaurant_menu_availabilities || [])
          .map(a => a.service),
        tax_category_id: taxLookupMap[gItem.tax_category_id] || null  // v2
      };

      // Convert item-level modifier groups
      for (const gGroup of gItem.groups || []) {
        const unified = unifyGroup(gGroup);
        item.modifier_group_ids.push(unified.id);
        if (gGroup.required !== undefined || gGroup.allow_quantity !== undefined) {
          item.modifier_group_overrides[unified.id] = {};
          if (gGroup.required !== undefined)
            item.modifier_group_overrides[unified.id].is_required = gGroup.required;
          if (gGroup.allow_quantity !== undefined)
            item.modifier_group_overrides[unified.id].allow_duplicates = gGroup.allow_quantity;
        }
      }

      // Convert sizes
      for (const gSize of gItem.sizes || []) {
        const size = {
          id: uid(),
          label: gSize.name,
          price: gSize.price || 0,
          modifier_group_ids: []
        };
        for (const gGroup of gSize.groups || []) {
          const unified = unifyGroup(gGroup);
          size.modifier_group_ids.push(unified.id);
        }
        item.sizes.push(size);
      }
      result.menu.items.push(item);
    }
  }

  // 4. Add unified modifier groups
  result.menu.modifier_groups = Array.from(groupMap.values());
  return result;
}
