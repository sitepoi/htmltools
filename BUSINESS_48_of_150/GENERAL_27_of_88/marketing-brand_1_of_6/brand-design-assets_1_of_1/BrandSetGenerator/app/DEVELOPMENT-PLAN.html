🛠 Maintainer note — how to add a new asset (2-minute task)

The Brand Kit is fully data-driven. Most new assets only need one entry in makeAssets() — the sidebar menu, counts, cards, ZIP and brand.json manifest all update automatically.

{
  id: 'facebook-cover',                    // filename slug-facebook-cover.svg
  group: 'web',                            // ASSET_GROUPS id (or add a new group)
  title: 'Facebook Cover',
  desc: '820×312 cover with safe-area guide.',
  tag: 'SVG · PNG · WebP',
  webp: true,                              // adds WebP button + zip entry
  build: function () { return buildFacebookCover(cfg); },  // returns {svg, w, h}
  dark: false                              // dark preview background
}

For raster-pixel-perfect work reuse svgToPng (scale / pngW / mime options); new formats follow the icoSizes pattern. Always re-run node --check BrandSetGenerator.js && node check-ids.cjs && node smoke-test.cjs after edits.
