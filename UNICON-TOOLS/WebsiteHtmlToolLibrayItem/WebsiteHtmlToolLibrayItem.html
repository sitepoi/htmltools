Embedding parameters schema

Maps each parameter name to its default value. When the tool is added to a page, these values are passed to the widget - it reads them from gw.getPageParams() or its own config.

A parameters schema is a JSON object that maps each parameter name to its default value. The platform passes these to the widget when it is embedded on a page.

{
  "maxItems": 6,
  "autoplay": true,
  "cmsObjectType": "testimonials",
  "headings": ["Fresh", "Popular"]
}

Allowed value types: string (in quotes), number, boolean, array or object (JSON).

Values are JSON: strings need quotes ("USD"), numbers and booleans as-is, arrays and objects as JSON text.

External API connections

Website tools are embedded into pages server-side and may talk to outside APIs. Keep credentials here instead of inside the widget code - they are configured once and consumed by the platform when the tool runs. Secrets must never appear in the HTML/CSS/JS code.
