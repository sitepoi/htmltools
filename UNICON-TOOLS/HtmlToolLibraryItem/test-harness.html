Schema & validation

A parameters schema is a JSON object that maps each parameter name to its default value. The CMS field settings use this list; the tool itself calls tool.param(key, default) at runtime.

{
  "currency": "USD",
  "maximumStars": 5,
  "showAverage": true,
  "labels": ["Poor", "Fair", "Good"],
  "style": { "theme": "dark" }
}

Allowed value types: string (in quotes), number, boolean, array or object (JSON).

Values are JSON: strings need quotes ("USD"), numbers and booleans as-is, arrays and objects as JSON text.

An output schema is a JSON object that describes the shape of the value the tool saves with tool.setValue(). Each key maps to its expected type name.

{
  "rating": "number",
  "label": "string",
  "liked": "boolean",
  "tags": "array",
  "config": "object"
}

Type names: string / number / boolean / array / object. Nested shapes can be written as objects in the Editor tab.

Values are JSON: type names in quotes ("number"), nested shapes as JSON objects.
