About this page (reference notes)

Pick a group, category or subcategory on the left to browse its ideas; click an item in the list to see its details on the right. The Built status is derived AUTOMATICALLY from the repo - every tool folder under BUSINESS*/PERSONAL* is detected with its code files, docs and screenshots. Manual status (Backlog / Planned / In Progress / Skipped) applies to ideas without a built folder and is saved in this browser.

This page is the SSOT for the folder hierarchy - Export folder hierarchy downloads the structure in the folder-hierarchy-import.json schema with a new version number on every export.

Master data lives in catalog-data.js (the SSOT - the MANUAL region is edited via AI conversation; the GENERATED region is the repo scan). The JSON files in this folder (tool-ideas-catalog.json, folder-hierarchy-import.json, tool-publish-state.json) are exported copies refreshed by npm run catalog:build, and can also be exported on demand from the Actions menu. Manual work state (status for ideas without a folder, priority, notes) is saved in this browser (localStorage key uniconhub_tool_ideas_work_v1).

Select an item from the list to see its details.
