Application Ideas Catalog

Applications (cmsObjectType) are the covers that bundle html-tools inside field groups inside objects. Each application lists the business objects it defines and the html-tools it bundles.
About this page (reference notes)

Pick a group, category or subcategory on the left to browse its applications; click an item to see its details on the right. An application (cmsObjectType) is the container: html-tools live inside field groups inside objects of the application. Each application records the business objects it defines (the Objects chips) and the html-tools it bundles (the Bundled html-tools chips) - the tools themselves are filed separately in the html-tool library taxonomy.

This page mirrors the html-tool folder taxonomy 1:1 so an application and the html-tools it bundles live in the same conceptual space. Master data lives in application-ideas-catalog.json; the page embeds the same data inline and can re-export it from the Actions menu. Manual work state (status, priority, notes) is saved in this browser (localStorage key uniconhub_application_ideas_work_v1).

Select an item from the list to see its details.
