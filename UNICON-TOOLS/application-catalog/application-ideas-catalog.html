Application Ideas Catalog

Applications (cmsObjectType) are the covers that bundle html-tools inside field groups inside objects. Each application lists the business objects it defines and the html-tools it bundles.
About this page (reference notes)

Pick a group, category or subcategory on the left to browse its applications; click an item to see its details on the right. An application (cmsObjectType) is the container: html-tools live inside field groups inside objects of the application. Each application records the business objects it defines (the Objects chips) and the html-tools it bundles (the Bundled html-tools chips) - the tools themselves are filed separately in the html-tool library taxonomy.

This page mirrors the html-tool folder taxonomy 1:1 so an application and the html-tools it bundles live in the same conceptual space. The single source of truth is application-ideas-catalog.json - the page loads it live over http and falls back to the generated application-catalog-data.js copy on file://. After editing the JSON run node build-catalog-data.cjs (or npm run catalog:apps) to refresh the copy. Data source: -.

Global search: typing in the search box searches every application in the catalog, across all folders - each result shows the application's folder path, so you can locate an existing application in the applicationStore and file it under the correct folder. Clear the search to browse all applications, or click a group / category / subcategory to drill down. Manual work state (status, priority, notes) is saved in this browser (localStorage key uniconhub_application_ideas_work_v1).

Select an item from the list to see its details.
